01

How it works

Decentralized by design.
Connected by a common codebase.

⌖

Local nodes

One repository for every city

Each node publishes its own maps, analyses and datasets. Local deployments stay independent while following the same transparent structure.

↻

Shared evolution

One maintained core

All nodes track the latest tested OSWM codebase, keeping improvements consistent across the network.

◇

Open infrastructure

Static and inspectable

GitHub Actions refresh the data and GitHub Pages serves it without a proprietary application backend.

02

The toolkit

From individual features
to a citywide picture.

01

Webmap

Interactive vector-tile views of sidewalks, crossings, kerbs, stairways and pedestrian areas.

02

Accessible routing

Comparable routes for distance, wheelchair, blind or low-vision, and reduced-mobility profiles.

03

Data quality

Actionable checks that expose missing, inconsistent and outdated pedestrian-network information.

04

Hazard analysis

Profile-specific screening using kerbs, tactile paving, surfaces, barriers and terrain evidence.

05

Data Hub & API

Cloud-optimized downloads, ISO-aligned metadata and direct GIS-friendly access to node products.

06

Statistics

Citywide summaries that reveal coverage, tagging patterns and the age of mapped infrastructure.
